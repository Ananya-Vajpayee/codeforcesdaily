# Codeforces Daily

My daily practice repository for **Codeforces** problems.

I am using this repository to consistently practice competitive programming, improve problem-solving skills, and track my progress by solving problems regularly.

## 📌 Goals

* Solve Codeforces problems daily
* Improve DSA and competitive programming skills
* Learn different problem-solving techniques
* Maintain a record of solved problems
* Gradually solve problems of higher difficulty

## 🗂️ Repository Structure

Each problem is added separately with its **Codeforces problem number**.

```text
codeforcesdaily/
│
├── 2257B
├── ...
├── ...
└── ...
```

## 💻 Language

Solutions are primarily written in **Python**.
